כפר הדרדסים - גרסת אפליקציה לטלפון
=====================================

מה יש בתיקייה
- index.html            המשחק כולו (470 שאלות), עובד גם בלי אינטרנט
- manifest.webmanifest  שם האפליקציה, הצבעים והאייקון
- sw.js                 שומר את המשחק בטלפון כדי שיעבוד בלי רשת
- icons                 האייקון שמופיע במסך הבית

איך מתקינים
1. מעלים את כל התיקייה כמו שהיא לכתובת אינטרנט מאובטחת (https).
   כל אחסון של אתר סטטי מתאים, למשל GitHub Pages או Netlify.
2. פותחים את הכתובת בטלפון.
   - אנדרואיד (Chrome): תפריט שלוש הנקודות > "התקנת האפליקציה" או "הוספה למסך הבית".
   - אייפון (Safari): כפתור השיתוף > "הוסף למסך הבית".
3. מהרגע הזה יש אייקון במסך הבית, המשחק נפתח במסך מלא ועובד גם בלי אינטרנט.

שמירת התקדמות
ההתקדמות נשמרת בטלפון עצמו. מחיקת נתוני הדפדפן או הסרת האפליקציה מוחקת אותה.
